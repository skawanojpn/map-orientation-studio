# Map Orientation Studio

地図の中心・向き・投影法を自由に設定し、投影法による距離・方位・形の見え方を観察するためのブラウザアプリです。`axis-mapping` と `azi-rotate` を統合し、学習・比較・地図表現の検討を目的に開発しました。

正式リリース：**v1.0.0**

## 公開版

GitHub Pages：<https://skawanojpn.github.io/map-orientation-studio/>

リポジトリを公開する場合でも、アプリ本体に秘密情報やAPIキーは含めません。地図データと世界遺産データは外部の公開データを実行時に取得します。

## 主な機能

- 8種類の投影法：正距方位、メルカトル、イコールアース、正射方位、正距円筒、サンソン、モルワイデ、グード
- 中心経度・緯度、地図の回転、表示倍率の数値指定
- ドラッグ、Shift＋ドラッグ、ホイール、タッチピンチによる地図操作
- 中心地点の検索・分類・プルダウン選択・座標入力・地図クリック指定
- 任意の比較地点との距離・方位の比較
- 首都、主要都市、歴史都市、港湾都市、観光都市、世界遺産都市、軍事・歴史地点の分類
- 国境線、都市名、グリッド、中央軸、等距離円、大圏航路、歪み指示円のレイヤー切替
- 標準、日本、太平洋、オーストラリア視点などの地図プリセット
- 日本語／英語、Natureを既定とする5テーマ＋高コントラストテーマ
- 投影法と中心・軸・極の関係を説明する解説パネル
- URLハッシュへの表示状態保存、PNG出力

## 操作の基準

- 表示倍率は`100`が初期値・基準値です。大きくすると拡大、小さくすると広域表示になります。
- 地図の回転は、`0°`が北上、`90°`が東上、`180°`が南上、`270°`が西上です。
- 「標準表示に戻す」は投影法を変更せず、現在の投影法の標準中心・向き・倍率へ戻します。
- 「オーストラリア視点（南方上）」は、経度135°を基準に南方を上にします。オーストラリア自体を表示中心へ移動するプリセットではありません。

## 開発環境

Node.jsとnpmを使用します。

```bash
npm install
npm run dev
```

開発サーバーは通常 `http://localhost:5173/` で起動します。

## ビルド

```bash
npm run build
```

ビルドでは次の成果物を生成します。

- `dist/`：Viteの静的ビルド（再生成可能なためGit管理対象外）
- `docs/`：GitHub Pages用の静的成果物（公開用として管理）
- `gas/Index.html`：GAS HtmlService用のインラインHTML

## GitHub Pages

1. `npm run build`を実行する。
2. `docs/`をGitHubへコミット・pushする。
3. GitHubリポジトリのSettings → Pagesで、公開元に`main`ブランチの`/docs`を指定する。

このプロジェクトでは、ビルド済みの`docs/`をpushした後、GitHub Pagesのビルド完了を確認して公開版を更新します。

## Vercel

プロジェクトルートをVercelへ接続し、次の設定を使用します。

- Build Command：`npm run build`
- Output Directory：`dist`
- Install Command：`npm install`

## Google Apps Script

1. `npm run build`を実行する。
2. Apps Scriptプロジェクトへ`gas/Code.gs`、`gas/Index.html`、`gas/appsscript.json`を配置する。
3. `doGet`を持つWebアプリとしてデプロイする。
4. `gas/README.md`の権限・実行ユーザー設定を確認する。

GAS版も地図データを外部URLから取得するため、利用環境のネットワーク制約を確認してください。

## データと制約

- 国土・国境データ：World Atlasの公開データを実行時取得
- 世界遺産分類：UNESCO World Heritage DataHubを実行時取得。取得できない場合は内蔵フォールバックを使用
- 都市・歴史地点：アプリ内の検索用データ
- 海面高度・標高・水深機能：v1.0.0では採用していません。実データに基づく信頼できる表示品質を確保できなかったため、撤去しています。
- 地図データや世界遺産データの外部取得に失敗した場合、該当機能は制限されます。

## 再開時の確認

作業を再開する場合は、次の順に確認してください。

```bash
git status
npm install
npm run build
```

次に読むファイルは以下です。

- `WORKLOG.md`：実装履歴、公開履歴、既知の判断
- `Plan.md`：当初計画と今後の候補
- `Agent.md`：統合時の与件と設計方針
- `gas/README.md`：GAS配布手順
